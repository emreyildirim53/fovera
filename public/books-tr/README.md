# Turkish Localization Provenance

Checked on: July 18, 2026

This folder is **not** a dump of third-party Turkish eBooks.

What these files are:

- Each `*.tr.txt` file in this folder is a Fovera-local Turkish localization aligned to a matching public-domain English source in `../books/`.
- The upstream English source set is documented in `../books/licenses/` and was live-verified against Project Gutenberg on July 18, 2026.
- No commercial Turkish publisher edition or third-party Turkish eBook source is cited for these files.

What this means for provenance:

- `public/books/` contains the verified public-domain upstream text set.
- `public/books-tr/` contains first-party project localizations derived from that upstream text set.
